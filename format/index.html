Détail des Formats en Géomatique : De la Source à l'Usage Le choix d'un format dépend de l'étape du projet : on ne travaille pas avec le même fichier selon qu'on acquiert de la donnée sur le terrain ou qu'on la diffuse sur Internet.

1. Les Formats de Source (Acquisition)¶

Ces formats sont générés par les capteurs ou les logiciels de conception. Ils sont souvent "bruts" et nécessitent un traitement pour être intégrés dans un SIG.

CAO/DAO (Architecture/BTP) : .dwg (AutoCAD), .dxf (format d'échange).

Usage : Plans de réseaux, bâtiments ou cadastre technique.

Levés de terrain : .csv ou .txt (coordonnées GPS), .rinx (données satellites).

Usage: Importation de points d'intérêt ou de bornes géodésiques.

Lidar (Scan 3D) : .las, .laz (compressé).

Usage : Nuages de points bruts pour la création de modèles d'altitude.

Imagerie brute : .raw, .tiff (sans géoréférencement).

Usage : Photographies aériennes ou satellites avant traitement.

2. Les Formats de Travail (Gestion et Analyse)¶

Ce sont les formats optimisés pour les logiciels comme QGIS ou ArcGIS. Ils permettent de croiser les données et d'effectuer des calculs.

GeoPackage (.gpkg) : Le standard moderne de l'OGC.

Usage : Format de prédilection actuel. Il contient dans un seul fichier SQLite des couches vecteurs, des rasters et des tables attributaires.

Shapefile (.shp) : Le format historique d'Esri.

Usage : Encore très utilisé pour l'archivage simple, malgré ses limitations (nom de colonnes limité à 10 caractères, limite de 2 Go).

PostGIS : Extension spatiale de la base de données PostgreSQL.

Usage : Stockage massif et travail collaboratif multi-utilisateurs sur serveur.

GeoTIFF (.tif) : Image raster contenant des informations de projection.

Usage : Analyse d'occupation du sol, modèles numériques de terrain (MNT).

3. Les Formats de Diffusion (Échange et Web)¶

Formats conçus pour être légers, lisibles par des navigateurs web ou des outils grand public.

GeoJSON (.geojson) : Format texte basé sur le JSON.

Usage : Webmapping (OpenLayers, Leaflet). Très simple à intégrer dans du code informatique.

KML / KMZ (.kml) : Format basé sur le XML.

Usage : Grand public (Google Earth). Permet de visualiser des données sans logiciel SIG spécialisé.

GML (.gml) : Format d'échange officiel (ISO/OGC).

Usage : Utilisé pour les échanges administratifs et la directive européenne INSPIRE.

COG (Cloud Optimized GeoTIFF) :

Usage: Consultation d'images satellites très lourdes directement via le cloud sans téléchargement complet.
