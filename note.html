Interoperabilité¶

Qu'est ce que c'est :¶

GENERALITE¶

L'interopérabilité en géomatique, c'est un peu comme s'assurer que tout le monde parle la même langue dans une pièce remplie de gens venant du monde entier. Dans notre cas, les "gens" sont des logiciels, des bases de données et des capteurs.

a. Pourquoi est-ce crucial ?¶

Imaginez que vous travaillez sur un projet d'urbanisme. Vous avez :Le cadastre en format Shapefile (Esri).Le réseau d'eau en AutoCAD (DWG).Des photos satellites en GeoTIFF.Sans interopérabilité, vous passeriez 80 % de votre temps à convertir des fichiers au lieu de les analyser. L'interopérabilité permet de superposer ces couches instantanément.

b. Les différents niveaux d'interopérabilité¶

Pour que la magie opère, il faut que l'entente se fasse à plusieurs étages

c. Le rôle des standards (OGC)¶

C'est ici qu'intervient l'OGC (Open Geospatial Consortium). C'est l'organisme qui définit les "règles du jeu". Grâce à lui, nous utilisons des services web standardisés qui permettent d'afficher des cartes sans même télécharger le fichier source :

  • WMS (Web Map Service) : Pour afficher une image de la carte.

  • WFS (Web Feature Service) : Pour récupérer les données vectorielles (on peut modifier les points/lignes).

  • WMTS (Web Map Tile Service) : Pour un affichage rapide par tuiles (comme Google Maps).

c-1. Le rôle du Comité ISO/TC 211 : Le "Cerveau" de la Géomatique¶

Le comité technique 211 est celui qui définit le modèle conceptuel de l'information géographique. Sans lui, chaque pays définirait une "latitude" ou une "altitude" de manière différente.Son travail permet de répondre à trois questions fondamentales pour l'interopérabilité :

  • Quoi ? (Le contenu : ISO 19110 pour le catalogage des objets).

  • Où ? (La localisation : ISO 19111 pour les systèmes de coordonnées).

  • Quand ? (Le temps : ISO 19108 pour le schéma temporel).

c-2. Les Normes Clés de la série 19100¶

Pour bien comprendre l'impact du TC 211, voici les normes les plus utilisées qui garantissent que les données sont exploitables partout :

  • ISO 19115 (Métadonnées) : C'est la "carte d'identité" de la donnée. Elle dit qui a fait la donnée, quand, et quelle est sa précision. Sans métadonnées, on a de la donnée, mais on ne peut pas lui faire confiance.

  • ISO 19111 (Référencement spatial) : Elle définit comment on projette la Terre (ronde) sur une carte (plate). C'est grâce à elle qu'un point GPS tombe exactement au bon endroit sur votre fond de carte.

  • ISO 19136 (GML) : Elle définit le langage de balisage géographique. C'est le format de transfert standard pour échanger des objets géographiques sur le web.

I. Les Trois Piliers de l'Interopérabilité¶

Pour qu'un système soit réellement interopérable, il doit répondre à trois paliers :

Interopérabilité Technique : Capacité des systèmes à communiquer physiquement (protocoles réseaux, formats de fichiers comme le GeoJSON ou le GML).

Interopérabilité Sémantique : Garantie que le contenu est compris de la même façon par l'émetteur et le récepteur.

Exemple : Définir précisément si une "surface boisée" commence à partir de 10% ou 30% de couvert arboré.

Interopérabilité Organisationnelle : Mise en place de cadres juridiques et de partenariats pour que les administrations et entreprises acceptent de partager leurs données.

II. L'ISO / TC 211 : Le Cadre Théorique (La "Loi")¶

Le Comité Technique 211 de l'ISO est l'instance qui définit les modèles conceptuels de l'information géographique (série 19100).

1. Le Processus de Normalisation¶

L'ISO suit un cycle rigoureux pour garantir un consensus mondial :

Proposition & Préparation : Définition du besoin.

Comité & Enquête : Soumission aux experts des 165 pays membres pour vote et modifications.

Approbation & Publication : La norme devient une référence internationale officielle.

2. Les Normes Clés à connaître¶

ISO 19111 (Référencement Spatial) : Définit comment décrire la position d'un objet sur Terre (systèmes de coordonnées, projections).

ISO 19115 (Métadonnées) : La norme la plus célèbre. Elle définit comment documenter une donnée (auteur, date, précision, emprise géographique). C'est le "CV" de la donnée.

ISO 19110 (Méthodologie du catalogage) : Définit comment décrire les types d'objets (ex: qu'est-ce qu'une "rivière" dans ma base de données ?).

III. L'OGC : Le Bras Armé Technique (L' "Outil")¶

Fondé en 1994, l'Open Geospatial Consortium transforme les concepts théoriques de l'ISO en standards d'implémentation informatique.

1. Les Services Web Géospatiaux (Architecture Client-Serveur)¶

L'OGC a révolutionné la géomatique en créant des protocoles permettant de consulter des données à distance sans les télécharger :

WMS (Web Map Service) : Le serveur envoie une image (raster) de la carte. Idéal pour les fonds de plan.

WFS (Web Feature Service) : Le serveur envoie les vecteurs (points, lignes, polygones) avec leurs attributs. Permet l'édition et l'analyse.

WMTS (Web Map Tile Service) : Version optimisée du WMS découpée en "tuiles" pré-calculées pour une rapidité maximale (type Google Maps).

2. Les Formats de Données Ouverts¶

L'OGC promeut des formats qui ne sont pas liés à un éditeur de logiciel :

GML (Geography Markup Language) : Format XML pour le transfert d'objets (très complet mais lourd).

GeoPackage (.gpkg) : Le standard moderne. Une base de données SQLite légère, capable de stocker vecteurs et rasters dans un seul fichier.

KML : Standardisé par l'OGC pour l'affichage dans des globes virtuels (Google Earth).

IV. La Mise en Application : La Directive INSPIRE¶

La directive européenne INSPIRE est l'application politique de tout ce qui précède.

Objectif : Créer une Infrastructure de Données Géographiques (IDG) à l'échelle de l'Europe pour les politiques environnementales.

Obligation : Les pays membres doivent publier leurs données selon les normes ISO (pour la structure) et les standards OGC (pour la diffusion).

Résultat : Un expert français peut croiser des données d'inondations espagnoles avec des données d'occupation du sol allemandes sans aucune manipulation technique complexe.
