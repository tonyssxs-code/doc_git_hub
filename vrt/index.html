LE FORMAT VRT (VIRTUAL FORMAT)¶

Le format VRT est un fichier XML qui définit une "vue" sur une ou plusieurs sources de données. Sa grande force réside dans le fait qu'il ne duplique pas les données sources : il se contente de les référencer et d'appliquer des instructions de lecture.

Les Avantages Clés¶

  • Pas de duplication : Économie massive d'espace disque.
  • Flexibilité : Permet de mosaïquer plusieurs images ou de changer la projection "à la volée".
  • Interopérabilité : Parfaitement lisible par GDAL/OGR, QGIS, FME et la plupart des logiciels SIG modernes.

2. Astuce QGIS : Extension Spreadsheet Layers¶

Si vous travaillez avec des fichiers Excel ou LibreOffice, l'extension Spreadsheet Layers est indispensable. * Elle crée automatiquement un fichier VRT invisible pour charger vos données .ods, .xls, .xlsx. * Elle permet de gérer les types de colonnes (Entier, Texte, Date) bien mieux que le simple CSV.
